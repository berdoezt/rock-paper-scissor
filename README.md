# Rock-Paper-Scissors-Lizard-Spock (RPSLS)

A fun and interactive command-line game where you can play **Rock-Paper-Scissors-Lizard-Spock** against the computer! Reach 3 wins to become the champion.

## Features
- Classic RPSLS rules:
  - Rock crushes Scissors and Lizard.
  - Scissors cuts Paper and decapitates Lizard.
  - Paper covers Rock and disproves Spock.
  - Lizard eats Paper and poisons Spock.
  - Spock smashes Scissors and vaporizes Rock.
- Human vs. Computer gameplay.
- Randomized computer choices.
- Play as many rounds as you like!

## How to Play
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd rps
2. Run the game:
    ```bash 
    python3 main.py
    ```
3. Follow the on-screen instructions to make your choice and compete against the computer.

## Requirements
- Python 3.x
